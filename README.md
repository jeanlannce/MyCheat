# My Cheat

[Hearts of Iron IV](https://www.paradoxinteractive.com/games/hearts-of-iron-iv) 多功能作弊/增强 mod —— 基于 **Cheat Ideas** 面板框架深度重排，并整合 **TYGC** 的军工企业（MIO）与角色系统。

> 游戏版本：**1.19.3.0** ｜ mod 版本：**v2.1.0**（2026-10-10）

---

## ✨ 主要功能

### 一、面板式修改（24 个分类）

原 Cheat Ideas 面板经过**整体重排与改名**，按"内政 / 军事 / 情报 / 生产"逻辑重新归类：

| 分类 | 内容 |
|---|---|
| **内政** | 每日政治点、政治点%、稳定度、战争支持、科研速度、指挥点获取/上限 |
| **建筑** | 消费品工厂、建筑速度、资源获取、市场资源、工厂数、维修速度、免费维修 |
| **工业** | 工厂产出、生产效率上限/保持/增长、轰炸易损性、船厂产出、舰船维修 |
| **人口** | 人口增长、适役人口、动员速度、每周人力 |
| **外交** | 关系改善、贸易协定、各项紧张度限制、正当化时间 |
| **流亡与附庸** | 正统性、自治度、向宗主国贡献工厂/贸易 |
| **武装部队** | **无敌陆军 / 无敌海军 / 无敌空军** + **四栏精通度获取** ⭐ |
| **战争经验** | 陆/海/空经验获取与修正 |
| **志愿军与特种部队** | 志愿军派遣、航空上限、特种部队容量/下限 |
| **MIO（军工组织）** | 研究加成、资金、指派/更换/政策成本与冷却 |
| **设施与科学家** | 各类设施建造速度、补给消耗、女性科学家概率 |
| **特殊项目** | 各领域特殊项目研究速度 |
| **情报机构 / 特工行动 / 反间谍和密码学** | 情报、特工、密码学全系列 |
| **抵抗与镇压** | 驻军伤害、破坏效率、抵抗组织、顺从度 |
| **改造再利用** | 装备缴获、改装、转换速度与成本、资源短缺惩罚 |
| **队伍与训练** | 将领经验、军事领袖花费、训练时间与等级、战场宽度 |
| **装备设计** | 各兵种设计成本、陆/空/海装备设计商成本 |
| **其他1 ~ 其他5** | 核心领土攻击/防御、核武器生产、投降界限等零星项 |

### 二、「无敌」三合集 ⭐

**武装部队** 分类的前三行，把原来分散在陆军/海军/空军各栏的 buff **聚合**到一栏：

| 行 | 内容 | modifier 数 |
|---|---|---|
| 无敌陆军 | 组织度、士气、增援率、攻击、防御、速度、补给、计划、侦察、突破、堑壕、战场宽度、夜战、制空、损耗、HP、防空… | **27** |
| 无敌海军 | 组织度、士气、航速、航程、探测、命中、伤害、防御、防空、出击效率、登陆准备、经验… | **13** |
| 无敌空军 | 探测、航程、攻击、防御、机动、速度、任务效率、王牌、天气/夜间惩罚、事故率… | **25** |

> **数值规则**：每一档 = 各来源栏目**同档位**的真实数值（例如"+1 档"就是各栏 +1 档的原值组合），而非简单相加。

### 三、四栏精通度获取 ⭐

按 HOI4 的**子学说**（track）划分，而非军种级：

| 行 | 覆盖子学说 |
|---|---|
| 陆军精通度获取 | 装甲 / 步兵 / 战斗支援 |
| 海军精通度获取 | 主力舰 / 航母 / 屏卫舰 / 潜艇 |
| 空军精通度获取 | 战斗机 / 中型机 / 重型机 / 攻击机 |
| 特种部队精通度获取 | 特种一 / 特种二 |

### 四、图标显示

面板中 132 个栏目名带图标。图标资源**已重命名并独立化**（`GFX_mc_*` 前缀 + 独立目录），因此：

- **只开本 mod** → 图标正常显示
- **与 [Modifier Icons](https://steamcommunity.com/sharedfiles/filedetails/?id=2668048070) 同开** → **零冲突**

### 五、决议入口（TYGC 移植）

- 决议 **「解锁军工企业」** → 17 家 MIO 可见
- 决议 **「获得全部角色」** → 58 名角色（35 将领 / 52 含顾问 / 6 科学家）

## 📦 安装

1. 把 `my_cheat` 文件夹 与 `my_cheat.mod` 一起放入：
   ```
   C:\Users\<用户名>\Documents\Paradox Interactive\Hearts of Iron IV\mod\
   ```
2. 启动游戏，在启动器中启用 **My Cheat**

**或**手写 `dlc_load.json` 绕过启动器：
```json
{"enabled_mods":["mod/my_cheat.mod"],"disabled_dlcs":[]}
```
